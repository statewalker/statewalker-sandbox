Session model prototype

A throwaway prototype for the ticket "How does a user session start agent sessions, and can the two merge?"

The question. A user session turns a person's access token into a capability, which their roles decide. From it the person starts agent sessions. Each one is a conversation with one agent, on a narrower capability, with its own tools, turns and items.

Push the model through the awkward cases:

  • the mode changes while an agent is working;
  • an admin demotes the user;
  • the token expires during a long run;
  • a session is revoked;
  • a sub-agent asks for more tools than its parent holds.

Then switch the view to One kind of session to see the same state as one session tree. That view shows what merging the two kinds would mean.

Two kinds or one: what the prototype shows

Two kinds (user session + agent sessions)One kind (a tree of sessions)
Who holds the modeThe user session. Agent sessions may only add a stricter one.The root session, inherited down the tree. Same rule, but every node carries a mode field that only the root may loosen.
Turns and itemsOnly agent sessions have them.The root has none, so "turns" is empty on one node of every tree.
LifetimeThe user session outlives a single access token, and a new token resumes it. Agent sessions live until they finish or are revoked.The same, but a node's lifetime rule now depends on whether it is the root.
Where it runsThe user session runs in the Workspace DO, next to the gate and the revocation list. Each agent session runs in its own DO with the core.Again the root needs the Workspace DO and the other nodes need agent DOs, so the host still tells them apart.
RevocationRevoking the user session stops all its agent sessions. Revoking one agent session also stops its sub-agents.Revoking a node stops its subtree. This is a single rule, and the one real simplification.
API/user-sessions and /sessions (threads) are separate resources.One /sessions resource, where the root is a session with no agent and an OpenAI-style thread is a non-root session.
