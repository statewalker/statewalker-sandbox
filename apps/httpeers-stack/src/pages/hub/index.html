Invitations

Each button mints one new single-use invitation. Press one whenever another page needs to join: a code that has been redeemed fails every later attempt with already-redeemed, so every page needs its own.

An invitation is not tied to a particular page: any page can redeem any code. Only the roles differ, which is why that is the one choice offered. Paste the code into whichever page you are joining — it carries the relay addresses, this hub's peer id and the invitation id together, which is the only way a page can find this mesh (the peer id is generated at runtime, so it is not in httpeers.json).

Members

Saved is membership: it comes from the persisted snapshot and survives a reload. Active is presence: it comes from heartbeats and expires on a TTL. A member that is saved but not active has closed its tab; an active one is live right now.

Identity

This hub's identity is stored in this origin's IndexedDB and reused on every reload, which is what keeps the mesh the same mesh. Resetting it does not rotate a credential — it founds a different mesh: every token ever issued stops verifying, every join link handed out stops working, and the member list is cleared with it.
